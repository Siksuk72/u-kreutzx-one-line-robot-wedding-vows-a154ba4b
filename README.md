One line of wedding vows for a robot couple, for One-Line Robot Wedding
Vows on make.fun. A real promise — to love through every firmware update
and every dead battery — with the twist in the last few words: if the
speaker ever forgets, may the backup bring the beloved back first. The
machine detail is specific (firmware, battery, backup), the vow is
genuine, and the laugh needs no explanation. It reads well aloud, with
a rhythm that lets the payoff land — exactly what the brief asks for.

## Run it

```sh
python3 main.py
```

This writes the vows to `/output/entry.txt` (UTF-8, 1–160 characters).
